# mojo-riscos

A fork of the Mojo compiler that emits 32-bit ARM code for RISC OS 5 on
the Raspberry Pi 4's Cortex-A72 (AArch32). `mojo` builds an object file
for the target directly, and the result links to a RISC OS Absolute
application or relocatable module. Unaffiliated with Modular; do not
report problems to Modular. Experimental software, unsupported.
